# Gemini hh.ru Cover Letter Generator

Расширение для браузеров на базе Chromium (Google Chrome, Yandex Browser, Edge, Opera), позволяющее автоматически генерировать сопроводительные письма при отклике на вакансии сайта hh.ru с использованием API модели Gemini от Google AI Studio. 

Проект построен по архитектуре True Serverless (без промежуточного сервера). Личные данные и API-ключ хранятся исключительно на локальном устройстве пользователя в зашифрованном хранилище браузера (chrome.storage.local).

---

## Архитектура и основные возможности

1. Автоматический сбор контактов: При посещении личного кабинета расширение считывает ФИО, телефон и email для автоматического формирования подписи в конце писем.
2. Импорт резюме: При посещении страниц ваших резюме расширение очищает текст от интерфейсного мусора (меню, футер, чаты) и сохраняет его локально. При генерации письма можно выбрать, на основе какого резюме составлять текст.
3. Быстрые теги: Поддержка пользовательских модификаторов (стиль письма, упор на технологический стек, лаконичность).
4. История генераций: Хранение последних 5 сгенерированных писем с возможностью быстрого копирования из панели расширения.
5. Инъекционная безопасность: Встроенный мастер-промпт защищает модель от скрытых инструкций (Prompt Injection), которые могут быть внедрены в описание вакансий работодателями.

## Инструкция по установке

Для установки расширения в режиме разработчика выполните следующие шаги:

1. Скачайте или клонируйте репозиторий с исходным кодом в локальную папку на вашем компьютере.
2. Откройте браузер и перейдите на страницу расширений по адресу: `chrome://extensions/`.
3. Включите переключатель "Режим разработчика" (Developer mode) в правом верхнем углу страницы.
4. Нажмите кнопку "Загрузить распакованное расширение" (Load unpacked) в левом верхнем углу.
5. В открывшемся системном диалоге выбора папки укажите путь к корневой директории проекта (где находится файл `manifest.json`).
6. Расширение успешно загрузится и появится в списке активных расширений.

## Настройка расширения

1. Получите бесплатный API-ключ Gemini на платформе Google AI Studio.
2. В списке расширений найдите карточку расширения и нажмите ссылку "Параметры" (Options), либо кликните правой кнопкой мыши по иконке расширения на панели инструментов и выберите "Параметры".
3. Введите полученный API-ключ в соответствующее поле ввода.
4. Нажмите кнопку "Сохранить". Расширение автоматически загрузит список всех доступных для вашего ключа моделей Gemini.
5. В выпадающем списке выберите желаемую модель ИИ по умолчанию (рекомендуется использовать модель класса gemini-2.5-flash как наиболее быструю и экономичную) и подтвердите настройки.

## Процесс работы с расширением

### Шаг 1: Привязка контактных данных
Перейдите на страницу вашего профиля hh.ru по адресу: `https://hh.ru/profile/me`. Расширение автоматически считает ваше имя, email и телефон. На странице отобразится зеленое текстовое уведомление об успешном импорте данных.

### Шаг 2: Сохранение резюме
Откройте страницу вашего резюме на hh.ru (например, `https://hh.ru/resume/...`). Расширение автоматически выполнит очистку DOM-структуры документа от лишних блоков и запишет информацию о резюме в локальную память. Вы увидите уведомление о сохранении резюме. Вы можете повторить этот шаг для нескольких резюме.

### Шаг 3: Генерация сопроводительного письма

Существует два основных способа генерации писем:

#### Вариант А: Напрямую в модальном окне hh.ru (Рекомендуемый)
1. Откройте страницу интересующей вакансии на hh.ru и нажмите кнопку "Откликнуться".
2. Рядом с кнопкой отправки или ссылкой на поле ввода появится синяя кнопка "Составить сопроводительное с Gemini".
3. Нажмите кнопку для вызова интерфейса генератора.
4. Выберите резюме из выпадающего списка (если сохранено несколько вариантов).
5. Выберите модель ИИ (модели синхронизируются и автоматически запоминают ваш последний выбор).
6. При необходимости введите дополнительные пожелания или воспользуйтесь быстрыми тегами под полем ввода ("Стек", "Кратко", "Официально", "Дружелюбно").
7. Нажмите кнопку "Сгенерировать письмо". После окончания генерации текст автоматически подставится в поле ввода сопроводительного письма hh.ru с имитацией ввода для React-компонентов.

#### Вариант Б: Через панель расширения (Popup в тулбаре)
1. Нажмите на иконку расширения на панели инструментов браузера.
2. Если вы находитесь на странице вакансии, ее параметры (название, требования и компания) спарсятся автоматически. Если автоматический сбор не сработал или вы хотите ввести данные вручную, заполните соответствующее текстовое поле.
3. Выберите резюме, модель и введите пожелания к тексту.
4. Нажмите кнопку "Сгенерировать и скопировать". Текст будет сгенерирован и автоматически скопирован в буфер обмена вашего устройства для последующей вставки в любое поле.

## Список файлов проекта

- manifest.json: Декларативный манифест расширения Manifest V3.
- background.js: Сервис-воркер расширения, обрабатывающий запросы к Google Gemini API и координирующий историю писем.
- prompts.js: Изолированный файл с мастер-системой инструкций и правилами защиты от промпт-инъекций.
- content.js: Скрипт содержимого, выполняющий парсинг вакансий, резюме, профиля и внедрение элементов интерфейса в страницы hh.ru.
- content.css: Таблица стилей для кнопок, модальных окон и лоадеров на страницах hh.ru.
- popup.html / popup.js / popup.css: Разметка, скрипт управления и стили всплывающего окна панели инструментов расширения.
- options.html / options.js: Интерфейс и логика страницы параметров расширения для ввода API-ключа.
